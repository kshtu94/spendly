Context Window -- Claude Code 

A context window is the amount of information (in tokens) that
a model like Claude Code can see and remember at one time while 
generating a response.

Think of it as the model's working memory.

Context is All the information availbale to understand something 
correctly.


Lets say You are Programmer/Application Developer 

1. Codebase -- Every single detail of your Code Base , what you have 
done so far , what r u trying to build and what r the next steps you 
should use while going forward.
2. PRD/Spec --
This PRD or Spec document , consists of complete requirement , where 
it is written what type of application to be built , so from here as well
we get our software development context.
3. JIRA/GitHub issues--
In Jira or GitHub where you receive every day tasks or the issues to be 
resolved , from here you also pick your context.
4. Slack/messages --
From Slack / messages , you can get context .
5. Previous AI Chats-- 
Same goes for previous Chats with AI , you can give context to
6. Git history/PRs--
The whole git repo where you are working , you get all the context from there
as well.


Context Window = the maximum amount of context the model can hold at once.


###################### NOTE ###########################

Claude Code has context window of 200k tokens 

Each new session starts with a fresh context window

Tokens are consumed by both your messages and Claude's
replies.

Claude's replies consume roughly 6x more tokens than your 
messages.

Lets say you are in a situation where you are stuck or 
almost about to fill/close to filling your context Window.

How to Resolve that ?


Stage1. Quality Degrades.

Stage2. Auto-Compaction Triggers (~75-92% Full)

Stage3. Repeated Compaction Causes Corruption

Stage4. Hard Stop

So this above Work is Done by Claude Itself .

so far within my session , Summarizes it and Stores in

this can create a problem , lets say in between your

till now whatever chat conversation has happened may be

ersation and Started Summarizing it , which may indeed 
result in Incomplete Info. Summary so far with Claude 
Conversation.

whereas 

in Case of Manual Periodic Checks , you can decide when to
create compacts lets say you are close to 70 - 75 % or in 
between it . You do it on your Own.
